# Kim To'laydi? — Restoran Cheki 🧾

365 kunlik ijodiy loyihalar challenge — **27-kun**.

Do'stlar bilan ovqatlanib bo'ldingizmi? Ismlarni kiriting — dastur termik printer uslubidagi chek "bosib chiqaradi" va oxirida tasodifiy ravishda kimdir "TO'LAYDI" muhri bilan belgilanadi.

## Xususiyatlari

- Ixtiyoriy sonda ism qo'shish/o'chirish
- Har bir ism uchun tasodifiy taom va narx bilan "chek qatori" ketma-ket chiqadi (printer effekti)
- Umumiy summa avtomatik hisoblanadi
- Oxirida tasodifiy "to'lovchi" tanlanadi va qizil muhr bilan tasdiqlanadi
- Yirtilgan chek qog'ozi estetikasi (zigzag pastki qism)

## Ishga tushirish

`index.html` faylini brauzerda oching. Hech qanday server yoki kutubxona kerak emas.

## Texnologiyalar

- HTML5 / CSS3 (clip-path, animatsiya) / Vanilla JavaScript (async/await)
